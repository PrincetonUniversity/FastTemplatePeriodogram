## 2. Efficiency hunt — vetted wins (24 proposals, skeptic-vetted)

### SOLID + SAFE/FREE (adopt; no science decision)
CPU engine (compound ~2–2.5× on staged-H detection, multiplies the banked 12–14×):
1. **Newton polish 8→3 steps** (knee measured: n=3 max rel dP 7.4e-15; n=2 breaks) — ~1.3× e2e. Spec floor is 6 (WP C2) ⇒ implement as early-exit or amend VERIFICATION.md + rerun scan suite.
2. **Bernstein candidate filter before polish** (drop grid maxima that provably can't win: gain ≤ (π/M)²(2H)²/2) — ~1.15× incremental.
3. **Bernstein-gated deep-dip fallback** (reuse the C3.5 M_needed test; skip per-row eigvals where the grid already brackets) — 1.05–1.25×; grows on ill-conditioned data. Recompute gate at densified M (naive recursion re-flags).
4. **Direct-sums trig recurrence** (one complex exp + harmonic recurrence; fused variant 3.3× on S1) — ~1.2–1.3× at H≤4. Reject the freq-cumprod variant (1.5e-8 drift).
5. **Hoist/cache template-independent stacked sums across the K-vocab + subtype scans** — 1.15–1.5× on catalog scans, bit-identical.
6. Powers-only micro-trims — ~1.02×.

GPU (fold into Track-A kernel design *before* writing it):
7. **Candidate compaction** (polish only real local maxima, not fixed Cmax=4H) — 2–2.5× on the existing CuPy proto, FREE, bit-identical (measured).
8. **Shared-memory coef staging + on-the-fly derivative weights** in the fused kernel — protective 1.5–3× vs a naive register-only first cut.
9. **Device-resident sums reuse** across K templates + subtype H-prefix sharing — 1.15–1.25×.
10. **Chebyshev trig recurrence** in the Stage-1 kernel — ~1.1×.

Vetted **do-not-dos** (recorded so they're not re-litigated): CUDA graphs /
persistent kernels (~1.02 ceiling), H2D/D2H stream overlap (~1.00), Aberth
wiring *deprioritized* (schedule-only; dip-row CPU round-trip costs ~0.5–2.7 %
at H=4 detection, 0 % at H=2 — revisit only if B4 measures a high real-cadence
dip rate). Numba/Cython polish kernel deprioritized unless polish-free
detection is rejected by Track B.

- **Polish-free detection** (grid+dip argmax; polish only top candidates) — ~1.2–1.5× incremental. Needs recovery-neutrality arm (B7).

## 3. Corrected Track-B plan (harness fixes applied in `trackB/`)
- PS1 single-epoch error model: σ = 1.0857/SNR, SNR = 5·10^(−0.4(m−m5)),
  m5 = {g 22.0, r 21.8, i 21.5, z 20.9}, floor 0.013 ⇒ σ(r=21.0) ≈ 0.10.
- Amplitude: per-subtype **true peak-to-peak** distributions (RRab p2p_g ~ U(0.5, 1.2),
  RRc ~ U(0.2, 0.5)), rescaled by each shape's measured p2p; griz ratios via BAND_AMP.
- Cadence: nights (with seasonal windows) → **same-night TTI pairs** (~20–40 min
  spacing), per-band night assignment — the PS1 3π structure that drives 1-day aliases.
- Held-out split: vocab from half the BV stars, truths from the other half
  (absolute rates + K-lever); paired H-comparison unaffected.
- Measurement queue: **B1** recovery-vs-H (per-H converged grids, paired) →
  **B4** deep-dip/deferral rate on real ZTF + PS1-like cadences → **B3** vocab-size
  (held-out) → **B6/B7** cascade-survival + polish-free-neutrality (new, from §2)
  → **B5** real nfreq/candidate-count ⇒ rebuild the §3 cost table bottom-up.
  (B2 regularization-recall unchanged, after B6 — the cascade may subsume it.)
